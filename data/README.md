# Dataset Information

## Source

The dataset used in this project contains historical weekly West Texas Intermediate (WTI) crude oil spot prices.

Source:

U.S. Energy Information Administration (EIA)

Dataset:

Weekly Cushing, OK WTI Spot Price

## Variables

The dataset primarily contains:

- Date: Week-ending date
- WTI Price: Crude oil price in U.S. Dollars per Barrel

## Data Usage

The dataset was used for:

- Historical price trend analysis
- Exploratory data analysis
- Stationarity testing
- ARIMA model development
- 26-week price forecasting
- Comparison with a Random Walk baseline

## Note

The raw dataset is obtained from the U.S. Energy Information Administration (EIA).

Users can download the latest version of the dataset directly from the official EIA website.
